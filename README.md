# SnowFox 🦊❄️

Paper 1.21.11 snow fox pet plugin (Java 21).

**Status:** repository setup in progress. Do not install until the Java source is committed and the GitHub Actions build succeeds.

## Build
Run `mvn clean package` or download the successful **SnowFox-plugin** artifact from GitHub Actions.

## Important
Disable `alastorfox.sk` before enabling this plugin. The plugin uses its own `pets.yml` and does not automatically import existing Skript registrations. Back up your worlds and Skript variables before testing.
